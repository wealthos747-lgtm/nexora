# Nexora

Personal KAM performance OS: upload RedBus reports, see dashboards, KRA scorecard, trackers, work log, compare and appraisal.

- **Website:** published by GitHub Pages from `www/` on every push to `main`.
- **Android APK:** built by GitHub Actions (Capacitor) on every push; download it from the latest Release.
- **Data:** stays on the device that uses it (browser storage). No report data is in this repository.
